# Figure sources

The figures on the assignment page show **actual product interfaces or biological data**. They illustrate tools and analysis methods; none is a result that students are expected to reproduce for the assigned samples. Each figure is stored locally so the page renders without depending on an external image host. Product interfaces and model lists may change after capture.

| Figure on the home page | Source and interpretation |
| --- | --- |
| Claude Science (`claude-science-workflow.webp`) | [Official Claude Science product page](https://claude.com/product/claude-science), showing an scVI parameter sweep and notebook. It is a product illustration, not an assignment result. |
| GPT-Rosalind (`gpt-rosalind-single-cell.webp`) | [Official GPT-Rosalind page](https://openai.com/gpt-rosalind/), showing an example single-cell QC workflow and saved artifacts. It is a product illustration, not the PBMC3k answer. |
| OpenScience workspace (`openscience-workspace.png`) | [Synthetic Sciences OpenScience project screenshot](https://github.com/synthetic-sciences/openscience/blob/main/assets/workspace.png), from the Apache-2.0 licensed project ([license](images/licenses/OpenScience-LICENSE.txt), [notice](images/licenses/OpenScience-NOTICE.txt)). It shows a product demonstration with EGFR data, not a student analysis. |
| OpenRouter free-model collection (`openrouter-free-models.png`) | Screenshot captured for this page in September 2026 from the [public OpenRouter free-model collection](https://openrouter.ai/collections/free-models). | EGFR structure (`egfr-4hjo.jpeg`) | [RCSB PDB 4HJO](https://www.rcsb.org/structure/4HJO), deposited by Park and Lemmon: experimental inactive EGFR kinase domain with erlotinib. No mutation is highlighted. |
| EGFR ligand distances (`egfr-ligand-distances.png`) | Computed for this assignment from the bundled [RCSB PDB 4HJO coordinates](https://www.rcsb.org/structure/4HJO) using `scripts/render_4hjo_contacts.py`. | QC violin plots (`scanpy-qc-example.png`) | [Scanpy preprocessing and clustering tutorial](https://scanpy.readthedocs.io/en/stable/tutorials/basics/clustering.html#quality-control), showing quality metrics for a BMMC example dataset. This is not PBMC3k. |
| Resolution comparison (`scanpy-resolution-example.png`) | [Scanpy preprocessing and clustering tutorial](https://scanpy.readthedocs.io/en/stable/tutorials/basics/clustering.html#clustering), showing the same BMMC embedding with three Leiden resolutions. This is not PBMC3k. |
| PBMC UMAP (`pbmc-reference-umap.png`) | Plotted for this assignment from the real 700-cell `pbmc68k_reduced` dataset distributed with [Scanpy](https://scanpy.readthedocs.io/en/stable/tutorials/plotting/core.html), using its stored UMAP coordinates and reference `bulk_labels`. The underlying PBMC68k data are from [10x Genomics](https://www.10xgenomics.com/datasets/fresh-68-k-pbm-cs-donor-a-1-standard-1-1-0). The plotting source is `scripts/render_reference_umap.py` in this repository. This is **not** the PBMC3k assignment result. |
| V1 Adult Mouse Brain tissue (`visium-v1-input-tissue.png`) | Copied without alteration from `spatial/tissue_lowres_image.png` in the [10x Genomics V1 Adult Mouse Brain spatial archive](https://cf.10xgenomics.com/samples/spatial-exp/1.1.0/V1_Adult_Mouse_Brain/V1_Adult_Mouse_Brain_spatial.tar.gz) bundled under `datasets/`. This is the actual Task 3 histology input. |
| Visium tissue (`squidpy-visium-closeup.png`) | [Squidpy spatial plotting tutorial](https://squidpy.readthedocs.io/en/stable/notebooks/examples/plotting/plot_scatter.html), showing a cropped view of Sox8 expression and existing annotations over a mouse-brain Visium histology image. The [tutorial source repository](https://github.com/scverse/squidpy-tutorials) is published under [MIT](images/licenses/SquidpyTutorials-LICENSE.txt). These annotations are **not** the expression-only clusters requested in Task 3. |
| Neighborhood enrichment (`squidpy-neighborhood-enrichment.png`) | [Squidpy neighborhood-enrichment tutorial](https://squidpy.readthedocs.io/en/stable/notebooks/examples/graph/compute_nhood_enrichment.html), showing observed neighbors compared with permutations for a Visium example with existing region labels. It illustrates a statistic, not the assignment result. |
