    Figure sources

    The figures on the assignment page show actual product interfaces or biological data. They illustrate tools and analysis methods; none is a result that students are expected to reproduce for the assigned samples. Each figure is stored locally so the page renders without depending on an external image host. Product interfaces and model lists may change after capture.

    Figure on the home page Source and interpretation
    Claude Science (claude-science-workflow.webp) Official Claude Science product page, showing an scVI parameter sweep and notebook. It is a product illustration, not an assignment result.
    GPT-Rosalind (gpt-rosalind-single-cell.webp) Official GPT-Rosalind page, showing an example single-cell QC workflow and saved artifacts. It is a product illustration, not the PBMC3k answer.
    OpenScience workspace (openscience-workspace.png) Synthetic Sciences OpenScience project screenshot, from the Apache-2.0 licensed project (license, notice). It shows a product demonstration with EGFR data, not a student analysis.
    OpenRouter free-model collection (openrouter-free-models.png) Screenshot captured for this page in September 2026 from the public OpenRouter free-model collection. It shows the public catalog, not any account or API key. Names, rankings, and prices can change.
    EGFR structure (egfr-4hjo.jpeg) RCSB PDB 4HJO, deposited by Park and Lemmon: experimental inactive EGFR kinase domain with erlotinib. The image comes from the RCSB Structure Summary page; RCSB states these molecular images have the same CC0 terms as PDB archive data. No mutation is highlighted.
    EGFR ligand distances (egfr-ligand-distances.png) Computed for this assignment from the bundled RCSB PDB 4HJO coordinates using scripts/render_4hjo_contacts.py. The plotted values are nearest heavy-atom distances from chain-A residues to ligand AQ4. They are real geometry, but no mutation effect is inferred.
    QC violin plots (scanpy-qc-example.png) Scanpy preprocessing and clustering tutorial, showing quality metrics for a BMMC example dataset. This is not PBMC3k.
    Resolution comparison (scanpy-resolution-example.png) Scanpy preprocessing and clustering tutorial, showing the same BMMC embedding with three Leiden resolutions. This is not PBMC3k.
    PBMC UMAP (pbmc-reference-umap.png) Plotted for this assignment from the real 700-cell pbmc68k_reduced dataset distributed with Scanpy, using its stored UMAP coordinates and reference bulk_labels. The underlying PBMC68k data are from 10x Genomics. The plotting source is scripts/render_reference_umap.py in this repository. This is not the PBMC3k assignment result.
    V1 Adult Mouse Brain tissue (visium-v1-input-tissue.png) Copied without alteration from spatial/tissue_lowres_image.png in the 10x Genomics V1 Adult Mouse Brain spatial archive bundled under datasets/. This is the actual Task 3 histology input.
    Visium tissue (squidpy-visium-closeup.png) Squidpy spatial plotting tutorial, showing a cropped view of Sox8 expression and existing annotations over a mouse-brain Visium histology image. The tutorial source repository is published under MIT. These annotations are not the expression-only clusters requested in Task 3.
    Neighborhood enrichment (squidpy-neighborhood-enrichment.png) Squidpy neighborhood-enrichment tutorial, showing observed neighbors compared with permutations for a Visium example with existing region labels. It illustrates a statistic, not the assignment result.

    When preparing your own report, cite the structure or dataset you actually used and distinguish your computed output from a reference illustration.
